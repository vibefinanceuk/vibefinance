# 0134 — Say only what the screen cannot

**Status: built.** Success messages removed; refusals kept.

---

## The message that stayed on screen

> "Source retired. An email address was issued for it, so the record is
> kept."

Correct, translated, well-worded — and **noise**. It restated what the
list already showed, and sat there while somebody did the next thing.

**The list is the answer.** A retired source shows *"Retired"* beside
the address that kept it. A deleted one is gone from the table. Neither
needs a sentence.

---

## The line

The screen speaks only when it **cannot show** something:

- *"Give the source a name"* — nothing happened and nothing looks
  different.
- *"That name is too long for an email address"* — the same.
- *"Source retired. An email address was issued"* as a **refusal**, when
  somebody tried to rename and could not.

Every one is a case where a person pressed something and the screen
looks exactly as it did. **That is the only time a sentence is doing
work.**

---

## And a refusal does not outlive its action

Cleared on every render, so a complaint about one source cannot sit over
an action on another.

That was already possible before this: the note persisted until
something else wrote to it, so a message about a source somebody had
since deleted could still be on screen.

---

## What this cost

Decision 0132 built outcome codes so a person read *"Source deleted"* in
their own language. **Most of those are now never displayed.**

Not wasted: a refusal needs exactly the same treatment, and the codes
are what make it translatable. But it is worth saying plainly that the
work found its purpose one decision later than it was written.

---

## What is not built

- **The viewer still announces its saves.** *"Saved."* appears under the
  line table on every keying save, and the same argument applies: the
  exceptions panel and the fields are the answer.
- **Nothing distinguishes a refusal from a failure.** *"Give the source
  a name"* and *"could not load sources"* render identically, and one is
  a person's mistake while the other is ours.
