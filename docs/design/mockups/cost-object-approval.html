Cost-Object Priority

Shown because Mode is set to Cost-Object. Which cost-object dimension routes a line's approval, and in what order, when a line carries more than one. The highest-priority dimension that is both switched on and coded on the line wins; the rest are not consulted (see the walk-through below, and the open question in the design doc about whether this should instead require every enabled dimension to approve).

Reordering here would reuse the same drag control the Process screen's own stage sequence already has (decision 0352) — shown as up/down buttons in this static file only.

How a line would resolve

A worked example — an €8,400 line coded to GL Code 6100 (Office Supplies, no approver configured) and Cost Centre DE01 (Manufacturing DE, owner Alice Okafor, €5,000 limit, parent Cost Centre DE00 owned by Priya Shah with no limit set).

1. General Ledger Code — highest priority, not enabled → 2. Commodity Code — not coded on this line → 3. Cost Centre DE01 — Alice Okafor, €5,000 limit — exceeded → DE01 → DE00 — Priya Shah, no limit — covers €8,400 ✓
